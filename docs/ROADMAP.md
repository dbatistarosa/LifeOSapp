# LifeOS — Product Roadmap

## Phase 1 — MVP Web App ✅ BUILT
**Stack:** React 18 + Vite + Tailwind (Aurora Dark) + Supabase + Claude API  
**Target:** First paying users, $19/month  
**Key features:** Auth, onboarding, daily check-in, dashboard, AI coach, finance, music, sleep, squad, purpose  
→ See [phase1.md](./phase1.md)

## Phase 2 — React Native Mobile App
**Target:** 1,000 active users, $19,000 MRR  
**Key additions:**
- React Native (iOS + Android) via Expo
- Apple HealthKit + Google Fit integration
- Real-time squad chat (Supabase Realtime)
- Bank sync (Teller.io)
- Push notifications
- AI weekly PDF report
- Offline mode (WatermelonDB)  
→ See [phase2.md](./phase2.md)

## Phase 3 — B2B Teams + Advanced AI
**Target:** $100K MRR
